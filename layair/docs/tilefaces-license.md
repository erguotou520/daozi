# 牌面图集许可

`assets/resources/tiles/tilefaces.png` 由 [zddd312/mahjong-tiles](https://github.com/zddd312/mahjong-tiles)
的 34 张牌面合成：裁掉原图外层灰边，乘上牌桌的象牙底色，再排成 8×5 的图集并量化到 128 色。

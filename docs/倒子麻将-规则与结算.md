## 1. 牌与开局

- 136 张：万/筒/条 1–9 各 4 张（108）+ 分牌（东南西北中发白）各 4 张（28）。没有花牌。
- 东家 **14 张**、其余三家各 13 张；摸一张打一张。东家＝上一把成牌的人（流局则连坐），首把由开局掷骰的人坐东。
- 掷两颗骰子：**东家掷骰，骰子不改东家**；和值只按 `5=自己、6=下家、7=对面、8=上家` 循环决定**开牌墙**是哪一家，**留墩数取两颗骰子中较小的点数**。
- 每家牌墙 17 墩 × 2 张；取牌先上层后下层。
- **整圈牌墙是一条连续的牌**：从骰子定的开牌墙那头抓起，抓完这段接着下一段绕一圈，
  不是每家回头抓自己门前那面。发牌和打牌共用同一条队列。
- **方向：顺时针，每面墙从右往左**。自己这面墙从牌面右边抓起，抓到头接左手边那面，
  再往上是对面、右手边，绕回自己这面。
- **留墩**：开牌墙自己牌面右边留 `min(两颗骰子)` 摞不动，发牌从再往左一摞开始
  （1+4 → 右边留 1 摞，从第 2 摞起从右往左发）。留墩排到整圈最后才轮到。
- 发牌：东家起 3 轮 × 每轮 4 张，再每家 1 张，东家跳牌补 1 张（跳过下面那张），共 53 张。
  53 张 = 26.5 墩，超过一面墙的 17 墩，所以开牌那面会被抓掉大半、下一面吃掉一半，
  扣掉留墩后剩 83 张。
- 发完牌、看完手牌后选**缺门**。

## 2. 对局流程

- 可碰、可杠，**不可吃**（`1万 3万` 不能吃 `2万`）。
- 缺门：开局选定不可更换；手里有缺门牌必须优先打缺门牌，不能碰/杠缺门牌；打完缺门牌后可以正常出牌；之后摸到缺门牌必须打出。
- **三打一（翻牌）**：四家定缺后若三家缺同一门，缺另一门的那一家要把**三家缺的那一门**的牌翻开，
  之后摸到的这一门牌也亮着；其余手牌仍然扣着。该家成牌额外 +5 点、算 1 个小摸子。
  亮牌方一旦听牌要喊听，并在手牌前面亮出红色「听」；四家同缺或两两不同都不触发。
- 碰完立即打出一张；碰过的牌不能立即加杠。
- 明杠＝碰出的三张 + 第四张；暗杠＝手里四张相同。杠后从牌尾补摸一张，补完要打出，可以连续杠。
- 暗杠不能被抢；碰后加杠可以被抢。**被抢杠则杠取消**（那一把已经结束了）。
- **成牌优先**：别人打牌后先让原本有权成牌的人表态；此人明确放弃后其他人才能成牌。别人抢先喊成不代表原玩家失去优先权。
- 可自摸、可接别人打出的牌成牌、可在别人加杠时抢杠成牌。一把成牌即结束本牌；牌墙摸完流局。
- 四局后调圈：最后成牌的人掷骰子，点数指向的人位置不动，其余三人按顺时针调整位置。已实现在 `src/game/table.ts`，见第 6.1 节。

## 3. 本牌点数

```
本牌点数 = (∏ 倍数) × Σ 点子项
```

**没有牌型互斥**——「有多少牌型就算所有牌型的点数的和」。两处例外是结构性的：同一门里大连号不再重复计小连号；七对手里的四张相同算两对、不算刻子。

### 3.1 点子项

| 项 | 条件 | 点数 |
| --- | --- | --- |
| 成牌底点 | 任何成牌 | 4 |
| 自家三张（暗刻） | 成牌结构里真实存在的每刻（七对不算）；接牌成刻（成牌张是别人打的）按碰算 | +2；接牌成刻 +1 |
| 碰（明刻） | 每组 | +1 |
| 接牌成刻 | 对倒听牌，别人打出其中一张凑成刻子；只这一组按碰算，其余暗刻仍 2 点；自摸仍 2 点 | +1 |
| 杠 | 每组，明杠/暗杠同分 | +2 |
| 只子 | 同一门 ≥8 张，超出 7 的部分每张 1 点，上限 5 | 8→1、9→2…12→5 |
| 通 | 同一数字跨 **≥2 门**合计 ≥5 张，最多 8 通 | 5→5…8→8 |
| 压当 | 成牌张正好补顺子缺口，且**理论上只等这一张**：卡张（4_6 等 5）或边张（12 等 3、89 等 7）；两面和单吊不算 | +1 |
| 枯只压 | 压当（卡张/边张、只等这一张）成牌，且成牌张是**场上最后一张**：四张里另外三张都已亮在桌上（别家牌河/副露，**自己碰/杠出去的和自己打出去的也算**） | **+21**（在压当的 1 点之外额外加） |
| 单吊 | 成牌张正好补将牌，且**理论上只等这一张**；两面听补将（如 5678 等 5/8）不算 | +1 |
| 小连号 | **手牌**同一门连续六张（副露不参与；234456 不算，234567 才算） | +5 |
| 大连号 | **手牌**同一门 1–9 齐张（副露不算；同门不计小连号） | +20 |
| 双连号 | ≥2 门小连号，**逢2加1**：每 2 门小连号多计 1 门小连号的分（2 门 → +5、3 门 → +5、4 门 → +10） | +5/组 |
| 棒棒 | 同一门连续三组对子（223344） | +5 |
| 四活 | 四张相同且未开杠；碰出的三张 + 手里第 4 张也算，开杠的不算 | +10 |
| 不动手 | 整把没有碰过、没有杠过；**暗杠不算碰过/杠过，仍算不动手** | +5 |
| 草一色 | 只有一门数字花色 + 分牌 | +10 |
| 对对胡 | 全刻子/杠 + 一对将 | +10 |
| 七对 | 七个对子（四张相同算两对） | +31 |
| 大吊车 | 碰出四组后手把一独、单吊将（成牌即大拿） | +31 |
| 老小对 | **同一门里 1 和 9 都成坎**（至少 3 张，碰/杠也算），且不能被顺子拆用——11123 拆成 123 + 11 当将不算；命中一门即止（两门的话按双通算） | +5 |
| 三打一 | 三家缺同一门，不缺该门的人明牌打并成牌 | +5 |
| 杠开 | 杠后补摸成牌 | +5 |

### 3.2 倍数

| 项 | 效果 |
| --- | --- |
| 自摸 | 本牌点数 ×2 |
| 杠开 | 按自摸翻倍（计算器里杠开的 ×2 就是这一条，不再额外翻倍） |
| 杠后赛花 | **摸子**总额翻倍（不影响点数） |

## 4. 摸子

与点数独立的奖励，三家各自支付。

```
摸子数 = (∏ 摸子倍数) × Σ 摸子项
1 个大摸子 = 2 个小摸子 = 10 元；1 个小摸子 = 5 元
```

| 来源 | 大小 |
| --- | --- |
| 枯只压（接牌） | 1.5 个大摸子 |
| 枯只压（自摸） | 3 个大摸子 |
| 压当 | 1 个大摸子 |
| 单吊 | 1 个大摸子 |
| 普通自摸 | 1 个小摸子 |
| 三打一 | 1 个小摸子 |
| 清一色（大拿也照算） | 1 个大摸子，与自摸/压当叠加 |
| 清水（首牌大拿） | 1 个大摸子 + 1 个小摸子（即 1.5） |
| 杠后赛花 | 上述全部叠加后再 ×2 |

杠后赛花叠加示例：`1 个小摸子 → 1 个大摸子`；叠加三打一后三打一的小摸子也变大摸子；再叠加枯只压则自摸枯只压 3 个大摸子 ×2 = **6 个大摸子**。

**枯只压**：点数额外 +21 点，摸子同时照算（接牌 1.5 大 / 自摸 3 大）。因为自摸会把点数 ×2，`底 4 + 压当 1 + 枯只压 21 = 26 → 52 点`，**自摸枯只压必然是大拿**（已确认就是要这个效果）。

**枯只压的「最后一张」怎么数**：四张里另外三张只要已经亮在桌面上就算——
别家牌河里打出的、别家碰/杠出来的，**以及自己碰/杠出去、自己牌河里打出去的**。
例：自己碰了 2 万（三张亮在桌上），手里 1 万 + 3 万 卡 2 万，成牌张就是最后一张 2 万，算枯只压。
实现见 `src/game/game.ts` 的 `visibleCount(state, tile, null)`：传 `null` 表示自己的也算；
禁打提示那条仍用「只算别家」的口径（`excludeSeat` 传座位号）。

清一色示例：接牌成清一色 = 大拿 40 元/家 + 清一色 1 个大摸子（10 元）= **50 元/家**；自摸再叠 1 个小摸子 = **55 元/家**。

## 5. 大拿

触发任一条件即大拿：

1. 命中大拿牌型：清一色、双棒棒、双通、双四活、一一九、三杠、三大坎+同门2张、乱分、自摸大连号、**大吊车**。
2. **两个大牌型同时命中**，即 31 点牌型 + 10 点牌型——实际上就是**七对 + 四活**。
3. 含倍数后的点数 **≥ 50 点**（首牌即清水；大吊车自摸 31×2 = 62 点也必然触发）。
4. 一把成牌把其他三家的点数**全部清零**，即成牌点数 ≥ 三家剩余点数中的最大值。

补充说明：

- 七对**本身不是**大拿。
- 双连号、双杠**已不再是大拿**。双连号不是固定分，按构成累计：底 4 + 不动手 5 + 两门小连号 10 + 逢2加1 一门 5 = **24 点**；有压当或 8 只再 +1 到 **25 点**；成牌张是字牌（无压当）则停在 24（自摸首牌仍算大拿）。
- 双通：两个不同数字各自在两个花色里都达到 5 张以上。
- 双棒棒：`223344万 88万 445566筒` 这样的两组。
- 双四活：`122223 66万 455556条`，2 和 5 各有 4 张；可同花色。
- 一一九：整手牌只有 1、9 和分牌。
- 三大坎+同门2张：`111222333万 88万 234条`，或 `中中中发发发白白白`（不需要另外两张分牌）。
- 乱分：全是分牌，不要求成牌结构，同时算清一色。
- **结算**：大拿后普通点子全部不计算，**摸子照算**，其他三家各支付 40 元。

## 6. 大吊车禁打

- 大吊车局面（已碰/杠四组、手里只剩一对）打出其中一张后**开始禁打**。
- 禁打范围：打出的是数字牌则禁该数字 ±2（打 5 万 → 3~7 万）；打出的是**字牌则只禁那一张字牌**。
- **只要不换掉手上最后一支牌就一直禁**；换掉了就解除禁打。
- 只限制**不缺该门**的人；缺该门的人不受限制。
- 绝对安全可以打：外面已有 3 张，或外面 + 自己手上共 4 张。
- 违反者按点炮处理：**由打出禁牌的那一个人独自承担三家的钱**。大吊车成到算大拿，所以这个人要付三家的大拿金额（40 × 3 = 120 元），摸子一并由他承担。

引擎：`daLiaoCheForbiddenTiles(discarded)` 给禁打范围，`isAbsolutelySafe(visibleCount, ownCount)` 判绝对安全，
`scoreHand({ ..., singlePayer: true })` 输出「一人承担三家」的金额。

### 6.1 四局调圈

> 引擎：`src/game/table.ts` 的 `rotateSeatsAfterRound` / `seatOfPlayer`，`src/game/match.ts` 在局末调用；
> 网页和 LayaAir 的局末总账会标出「谁掷骰、谁位置不动」。

- **打满 4 局（不是 4 把）**才调圈；同一局里打多少把都不换位。
- 由**最后成牌的人**掷两颗骰子，和值按 `5=自己、6=下家、7=对面、8=上家`（相对掷骰者）数座位。
- 点数指向的那一家**位置不动**，其余三家按**顺时针**各自挪到下一个空位（空位＝除不动那家以外的三个座位）。
  例：`seats = [0,1,2,3]`、1 号位掷 7 点 → 3 号位不动，0→1、1→2、2→0，结果 `[2,0,1,3]`。
- 换座后赢家（下一局东家）跟着人走，下一局仍由他掷骰；累计账目、AI 标记也跟人走。
- 单机牌桌里「自己」始终显示在下方：引擎换完座后会整桌转回来让自己回到 0 号位，
  所以看到的是三家电脑按顺时针换位置；多人对局按各自的 `humanId` 转自己的视角。
- 一把结束：赢家就是下一把的东家，也由他掷骰子；流局则东家连坐。

## 7. 点数与金额结算

- 每一局每人 **50 点**，1 点 = **0.5 元**。
- 一家成牌，其他三家分别支付该家的点数。
- 先支付点数，**任意一家点数支付完，本局结束**；点数部分最多支付 50 点，摸子、大拿等金额另算。
- 摸子钱照常支付，且可以相互抵消。你举的例子：我大拿赢 50 元，另有大摸子一家、小摸子一家 → 大摸子那家只需付我 40 元，小摸子那家付我 45 元。
- 本局结束后统一清算每个人的实际输赢，不影响下一局；**下一局每人恢复 50 点**，赢家获得掷骰子权、坐下一把的东。

### 8.1 双连号算例（2026-10-17 确认）

双连号**不是固定 25 点**，按构成累计。基准手牌 `123456万 123456筒 55条`、两面成牌（成牌张不产生压当/单吊）、没碰没杠：

```
底点 4 + 不动手 5 + 小连号 5×2 + 逢2加1（每 2 门小连号再加一门 5）= 4 + 5 + 3×5 = 24 点
```

- 有**压当**（成牌张补顺子中张）或 **8 只**（某门满 8 张 → 只子 +1）→ **25 点**。
- **成牌张是字牌**（如字牌将、无压当）→ 停在 **24 点**；单吊字牌将仍按单吊 +1。
- 引擎开关：`Rules.doubleRunBonusEnabled`；回归见 `test-score.ts` 的 `[双连号]` 一节。

## 9. 引擎实现

`src/game/score.ts`（结算）：

- `scoreHand(input)`：输入手牌、副露、成牌张、自摸/杠开/三打一/首牌/别家可见张数等上下文，输出点数明细、大拿原因、摸子大小与金额。
- `input.singlePayer`：由一人承担三家金额（大吊车禁打点炮）。
- `decompose(counts)`：成牌结构拆解（4 组面子 + 1 对将）。
- `daLiaoCheForbiddenTiles(discarded)`、`isAbsolutelySafe(visibleCount, ownCount)`：大吊车禁打。

`src/game/table.ts`（桌位与局数流程）：

- `seatOffsetFromDice(sum)` / `seatFromDice(rollerSeat, sum)`：5=自己、6=下家、7=对面、8=上家循环。
- `rollOpening(rollerSeat, diceA, diceB)`：东家＝掷骰者（骰子不改东家），和值定开牌墙、留墩数（较小骰子）。
- `dealPlan(dealerSeat)`：3 轮 × 4 张 + 每家 1 张 + 东家补 1 张 = 53 张。
- `dealTrace(dealerSeat, wallSeat, breakStacks)`：把发牌摊成逐张（给谁、来自哪面墙第几墩第几层），
  与引擎的连续取牌完全同序：顺时针、每段墙从墩号 16 往 0 走，留墩排在整圈末尾。
- `rotateSeatsAfterRound(seats, rollerSeat, diceSum)`、`settleRound(state, winnerSeat, circleDiceSum?)`：赢家获得掷骰权、四局调圈；`seatOfPlayer(seats, id)` 把掷骰权换算到换座后的新座位。

`src/game/game.ts`（单把对局状态机）：

- `createHand(options)`：洗牌、留墩、发牌，或直接指定 `hands` / `piles`（测试与沙盒用）。
- `legalActions(state, seat)` / `applyAction(state, action)`：纯函数推进，动作有 `chooseShortage`、`draw`、`discard`、`win`、`claim`（碰/杠/成）、`pass`。
- `legalDiscards` / `playableDiscards`：前者给 UI/AI 的「安全牌」（已排除禁打牌），后者是规则上真正能打出的牌。
- `forbiddenDiscardsFor(state, seat)`：大吊车禁打范围；`banViolation` 记录打出禁牌的行为。
- `settleHand(state)`：本把结算，给出各座位的点数与金额变化、是否本局结束。
- `chooseAIAction(state, seat)`：确定性简易 AI（能成就成、能杠就杠、优先清缺门）。

状态机已覆盖的流程：掷骰开局 → 选缺门 → 摸牌（接续牌墙）→ 缺门优先打牌 → 碰/杠/成（成 > 杠 > 碰，再按离打出者的远近）→ 杠后从牌尾补牌 → 大吊车禁打与点炮单人承担 → 成牌结算 / 流局。

`src/game/match.ts`（局流程）：

- `createMatch()`：4 家各 50 点，第 1 局。
- `startHand(match, diceA, diceB)`：头家掷骰开一把，带上本局点数与首牌标记。
- `endHand(match, circleDiceSum?)`：结算本把并推进；有人点数被付完则本局结束。
- `applyHandSettlement(match, settlement, circleDiceSum?)`：把一把的结算落到局上（单测可直接喂构造好的结算）。
- 局末：清算实际输赢、累计到 `totalMoney`、各家点数恢复 50、把数归零；打满 4 局调圈。

与计算器代码的已知差异（以对话为准）：

- 计算器给加点子加了互斥组，但对话明确说「没有互斥」。
- 计算器里杠开额外翻倍 + 附 1 个大摸子；对话只说 +5 点、摸子按成牌类型判定后由杠后赛花翻倍。
- 计算器把七对当大拿牌型、把四活当普通加点子；实际是**七对+四活**才构成大拿。
- 计算器把七对手里的四张相同也当作暗刻加分；引擎只在成牌结构里真实存在刻子时才加。
- 计算器的只子/通/对子都是单选，无法表达两门只子、多个通、多组连号。

## 10. 剩余口径（已按当前理解实现，随时可改）

1. **调圈的旋转方向**：现按「自由座位升序循环后移一位」实现，例 `[0,1,2,3]` 指向座位 2 → `[3,0,2,1]`。
2. **大吊车禁打点炮**时，摸子是否也由打出禁牌的那一人一并承担（现按是，`singlePayer` 同时作用于点数与摸子）。
3. **调圈用的骰子**：现复用「和值 → 座位」的映射，两颗和值或单颗点数都能用。
4. **禁打牌的约束强度**：规则上「不能打，打了算点炮」，所以引擎把它做成「UI 给安全牌、硬打则记违规并算点炮」，而不是直接拒绝出牌。
